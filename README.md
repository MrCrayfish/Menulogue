## About
Menulogue is a simple wrapper mod that makes [Mod Menu](https://modrinth.com/mod/modmenu/) config entrypoint compatible with [Catalogue](https://www.curseforge.com/minecraft/mc-mods/catalogue) on Fabric. Menulogue is available for download on [CurseForge](https://www.curseforge.com/minecraft/mc-mods/menulogue) or [mrcrayfish.com](https://mrcrayfish.com/mods/menulogue) (Offical Website).
